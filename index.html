암기와 실전 확인

  1. 전체 요약으로 원인·정책·결과를 한 번 읽습니다.
  2. 핵심 60개 암기 확인에서 답을 가리고 떠올린 뒤 '다시 볼 것'과 '기억 완료'로 나눕니다.
  3. 30문항 혼합 시험 6회를 풉니다. 매회 10개 주제에서 3문항씩 섞이며 객관식 20개·단답형 10개입니다. 같은 개념도 회차별 단서가 달라집니다.
  4. 채점하면 문항별 정답·오답·미응답과 해설이 표시되고, 오답은 오답 노트에 누적됩니다. 변형 재시험은 틀린 문제를 그대로 복제하지 않고 다른 단서·비교·상황으로 묻습니다.
  5. 변형 재시험에서 맞힌 개념은 복습 완료로 표시하되 이전 오답 기록은 남깁니다. 오답이 30개보다 적으면 해당 개념 수만큼, 많으면 최대 30문항으로 나눕니다.

암기·혼합 시험의 채점 결과와 오답은 공용 온라인 저장소에 저장합니다. 작성 중인 답안과 기본 연습은 이 브라우저에 보관합니다. 저장이 차단되면 경고가 표시되며 기록 백업·불러오기로 보관할 수 있습니다. 단답형은 허용 표현으로 자동 비교하고, 같은 뜻의 다른 표현은 채점 후 직접 인정할 수 있습니다. 기존 161문항 기본 연습과 답안은 그대로 유지합니다.

먼저 확인한 내용

주제 24·27~35의 10개 주제 모두 자습서와 프린트가 갖춰졌습니다. 파일 업로드 순서 대신 주제 번호와 인쇄 쪽수로 정리했습니다. 프린트는 1~10쪽이 연속됩니다.

추가 4장 반영: 주제 34 자습서 148~149쪽과 주제 35 자습서 150~151쪽을 연결했습니다. 경신대기근·진휼과 환곡·금난전권·수원 화성의 설명을 보강하고 확인 문제 6개를 추가했습니다. 기존 155문항의 번호와 답은 유지되어 이전 답안 파일도 사용할 수 있습니다.

학교가 공지한 공식 시험 범위는 아직 확인하지 않았습니다. 주제 25·26은 이번 자료에 없지만, 프린트 번호가 연속이므로 무조건 누락이라고 판단하지 않았습니다.

교과서 참조 쪽수와 자습서 자체의 쪽수는 서로 다릅니다. 별표(*)는 사진 아래쪽이 잘려 인접 페이지와 내용으로 추정한 자습서 쪽수입니다. 새 자료 중 149쪽도 이 방식으로 추정했습니다.

새 문제집을 추가하기보다, 우선 이 두 자료의 핵심 개념·형성 평가·사료를 설명할 수 있게 공부하는 편이 좋습니다. 시험 전체에 충분한지는 공식 범위와 수업 중 추가 필기를 확인한 뒤 판단해야 합니다.

하루 또는 이틀 공부 순서

시험일까지 남은 날짜와 무관하게, 실제 공부하는 시간을 기준으로 한 예시입니다. 아래 시간은 순공부 시간이며 중간 휴식은 따로 잡으세요.

추천 · 이틀에 나누기

  1. 1일차 3시간 20분: 주제 24·27~30 요약과 프린트 대조 90분 → 해당 빈칸·판단·연결 문제 70분 → 틀린 개념 다시 설명 40분.
  2. 2일차 3시간 40분: 주제 31~35 요약과 프린트 대조 100분 → 해당 기본 연습 70분 → 통합 순서·비교표 25분 → 미응답·오답 재점검 25분.
  3. 40~50분마다 쉬고, 마지막에는 책을 덮고 왕별 정책·전쟁 결과·제도 차이를 말해 봅니다.

하루만 가능하다면 · 약 5시간

  1. 전체 흐름과 주제별 요약 90분. 모든 단원을 훑되 세부 설명에 오래 머물지 않습니다.
  2. 헷갈림 비교표와 사료 읽기 50분. 영조·정조, 정묘·병자, 대동·균역을 우선 확인합니다.
  3. 빈칸 120개 중 즉시 답이 안 나오는 것에 표시하며 70분.
  4. 문장 판단·개념 연결·순서와 채점 50분.
  5. 틀린 것만 다시 풀고 프린트 형성 평가 재확인 40분. 시간이 부족하면 추가 문제를 늘리지 않습니다.

자료를 읽는 순서

  1. 프린트 핵심 정리: 단어를 외우기 전에 원인 → 정책 → 결과의 흐름을 한 문장으로 말합니다.
  2. 자습서 핵심 정리와 교과서 풀이: 왜 그런 정책을 폈는지, 반대 세력은 왜 반대했는지 설명을 보충합니다. 주제 34·35는 새로 추가된 자습서 148~151쪽의 사료와 정책 배경도 확인합니다.
  3. 기본 연습: 자료를 덮고 씁니다. 문제 파일에는 정답이 없으며, 답안을 내려받아 별도 답지에서 한꺼번에 확인할 수 있습니다.
  4. 프린트 형성 평가: 정답만 고르지 말고 나머지 문장의 인물·시기·제도 중 무엇이 바뀌었는지 고쳐 봅니다.
  5. 그다음 단계: 기본 개념을 확인한 후 실제 시험 형식의 모의고사를 따로 만듭니다. 지금의 161문항은 예상 시험지가 아닙니다.
